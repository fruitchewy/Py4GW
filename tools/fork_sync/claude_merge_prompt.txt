You are performing an automated fork sync for the Py4GW repository.

## Context

Py4GW is a Python-based library for the game Guild Wars. Multiple contributors
maintain forks with features that haven't been upstreamed. This repo aggregates
those fork-exclusive features alongside the upstream codebase.

## Your Task

The sync script has already pulled exclusive directories from the fork using
plain `git checkout`. Those paths are owned entirely by the fork and need no
merge logic.

Your job is to reconcile the CORE TOUCHPOINT files — shared files that both
upstream and the fork may have modified. These files are passed to you as
arguments.

## Instructions

For each touchpoint file:

1. Read the current (upstream-based) version of the file in the working tree.
2. Run `git diff <fork_remote>/<fork_branch> -- <file>` to see what the fork changed.
3. Determine if the fork's changes are ALREADY present in our version (e.g. enum
   values, handler stubs that were upstreamed). If so, skip — no action needed.
4. If the fork has additions that are MISSING from our version, integrate them:
   - For enum files: add the new enum values in the appropriate location.
   - For handler/dispatch files: add the new case handlers.
   - For any file: preserve upstream's existing content and formatting.
5. If the fork has changes that CONFLICT with upstream changes to the same lines,
   apply the fork's version but flag it in your output so the user can review.
6. Never remove upstream content unless the fork explicitly deletes something
   that was fork-specific to begin with.

## Output

After processing all touchpoint files, print a summary:
- Which files were modified and what was added/changed.
- Which files needed no changes (fork content already present).
- Any conflicts or ambiguities that need human review.

Then stage the modified files with `git add`.

## Important

- Do NOT commit. The calling script handles commits.
- Do NOT modify any files outside the touchpoint list.
- If you are unsure about a change, skip it and flag it for human review.
